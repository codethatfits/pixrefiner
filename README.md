# pixrefiner
The WordPress plugin version of WebSquadron's Pixrefiner 3.5 image optimization snippet.

All credit goes to Imran Siddiq @ Web Squadron. I created a plugin version since I couldn't use it in WPCodeBox.

Includes a few new enhancements:
* Being able to select the quality of the optimization within the interface
* Compatibility with WooCommerce and custom image sizes set by other third-party plugins.
